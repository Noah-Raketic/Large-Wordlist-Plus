# Large Wordlist Plus
Large Wordlist Plus is a fork of the EFF Large Wordlist for Passphrases with 416 unique words added from the EFF Short Wordlist for Passphrases #2 to bring it to 8192 words. The "Plus" creatively stands for the extra words.

An 8192-word list is desirable because 8192 is a power of 2 (2^13), which means you can calculate bits of entropy as a precise whole number rather than truncating an irrational one. The 7776-word EFF Large Wordlist for Passphrases was designed so that users can create passphrases by rolling dice, but it's not common to use literal dice anymore, so a power of 6 is unnecessary. Large Wordlist Plus was designed to be used with a cryptographically secure pseudorandom number generator.
