# Large-Wordlist-Plus
Large Wordlist Plus is a fork of the EFF Large Wordlist for Passphrases with 416 unique words added from the EFF Short Wordlist for Passphrases #2 to bring it to 8192 words. The "Plus" creatively stands for the extra words.

An 8192-word list is desirable because 8192 is a power of 2 (2^13), which means you can calculate the entropy as a whole number rather than truncating an irrational one. The 7776-word EFF Large Wordlist for Passphrases was designed to be used with literal dice (as a power of 6), but it's not common to use literal dice anymore.
